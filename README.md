# 项目说明 · 《显影 / DARKROOM · one roll of film》

一个单文件网页 3D 小游戏。没有战斗，没有关卡，没有分数——只有一间下个月就要拆掉的暗房、一卷没冲的胶片，和一套必须按顺序等完的化学反应。

> 这是我们使用了豆包模型自主研发的游戏——《暗房显影》项目。仍在持续地开发与优化，项目的制作人是 ygl。

- 交付文件：`暗房显影.html`（约 800 KB，双击即可玩，断网也能玩）
- 设备：桌面 Chrome / Edge，或手机浏览器（建议横屏）
- 时长：一周目 8–12 分钟

---

## 一、这是什么

参考对象是那份《几猫国产3A大作》——集装箱港区、第一人称、波次射击。那套东西打动人的地方其实不是枪，而是**空间感 + 目标提示 + 按住交互**：你站在一个有体积的房间里，抬头就能看见该往哪走。

我把这套"骨架"拆下来，换了血肉：

| 参考物 | 本项目 |
|---|---|
| 港区 / 集装箱 / 敌人 | 暗房 / 走廊 / 影棚 / 药水 / 相纸 |
| 波次刷怪、清点 | 8 步冲卷流程，按化学顺序推进 |
| 射击、血量、失败 | 曝光、显影、停显、定影、水洗的时间等待 |
| 目标：打掉多少 | 目标：让影像浮出来 |
| 情绪：紧张 | 情绪：安静、发暗、有点舍不得 |

一句话："把枪换成显影盘，把敌人换成时间。"

## 二、怎么玩

走近物件，把准星对准它，屏幕下方才会出现提示；提示里的动词决定你按什么。

1. **开红灯**（安全灯开关）——白光会毁相纸，红灯是这间屋子唯一的安全区
2. **取胶卷**（桌上那卷）——顺便读到老周的便签
3. **配药**（D-76 显影液 / 停显液 / F-5 定影液，1:1，20°C）
4. **装片**（把胶卷装进显影罐，盖严）
5. **曝光**（按住不放，盯着曝光计走到 4.0 秒再松手；短了偏薄，长了烧掉高光）
6. **冲显**（显影 12s，中途跟着提示摇罐 3 次 → 停显 3s → 定影 5s → 水洗 4s，一步都不能跳）
7. **看片**（把湿相纸挂上绳，等它自己显出来）——绳上本来就挂着另一张，可以顺手看一眼
8. **下一卷**——第一张照片里有个背影，第二卷在影棚的相机包里

第二卷的等待时间更短（显影 7s、摇罐 2 次），因为你已经学会了。这一次快门交给你：站在那台大画幅前，自己转视角拍三格（构图随你，冲着窗、冲着灯、冲着椅子都行，冲着暗房只会拍出一格黑）；回暗房把三格压成一张接触印相冲出来——纸上第 3 格不是你拍的。最后走到影棚窗前，天光进来，结束。

## 三、操作

**电脑**
- `W A S D` 移动，`Shift` 快走
- 鼠标转向（点击画面进入指针锁定）
- `E` / `空格` 交互；**长按不松**用于曝光和倒药
- `Esc` 或 `P` 暂停；`Ⅱ` 按钮也可以

**手机**
- 左摇杆移动，右侧 56%×72% 区域拖动转向
- 右下按钮交互，按住不放即蓄力交互
- 右上 `Ⅱ` 暂停（手机上默认收起了键盘提示，操作说明里只列触屏项）

**暂停菜单**（`Esc`）
- 继续游戏（`Esc` 再按一次）
- 设置：灵敏度（0.5–2.0×）、音量、阴影开关、恢复默认（存 `localStorage`，只影响本机）
- 操作说明：按设备自动切换键位表
- 重新开始：需要连点两次确认，避免误触清档
- 项目说明：就是这一页

## 四、技术实现

- **单文件**：Three.js r128（UMD）内嵌 + 全部逻辑内联 + 绳上那张旧照片（约 55 KB JPEG，base64 内嵌）。打开即玩，无网络请求。
- **全程序化贴图**：瓷砖、墙板、木纹、金属、相纸、负片、流程海报、安全灯牌、窗外天光、颗粒、光晕、接触印相、影棚背景纸，全部用 `CanvasTexture` 现画。
- **几何**：只用 Box / Plane / Cylinder 拼，靠灯光和材质区分空间，不加载任何模型。
- **音频**：WebAudio 实时合成——底噪 + 58Hz 镇流器嗡鸣 + 开关、倒药、快门、水声、挂片、负片摩擦等一次性音效，不依赖音频文件。
- **状态机**：`safeOn → film → poured[3] → loaded → exposed → paperStep 0..4 → photos → seen[]`，任务文本由状态推导，不是脚本念白。
- **摇罐**：显影计时器里挂一条独立的窗口调度（首窗、间隔、窗口宽 2.2s），窗口内按 `E` 才算一次，错过计入 `miss`；摇够与不够分别写进旁白和照片说明，但不判死——只是让边缘发花。
- **曝光计**：曝光不再是"按满固定秒数"，而是松手即停的计量模式——按住时实时读秒，容差内提示变亮，回头看冲出来的照片（偏薄 / 正常 / 过曝）也各不相同。
- **实拍**：第二卷的三格是真的从玩家视角渲出来的——临时相机按 3:4 画幅渲染到离屏缓冲、读像素、翻转、自动测光后给增益，再压胶片曲线加颗粒暗角；不用截图，不依赖任何外部素材。全黑的一格会被丢弃并给出提示。
- **接触印相**：三格 + 一格空白排成 2×2，程序化画米纸底与纸纹，铅笔编号，现拼成第二张照片。
- **交互判定**：距离（默认 1.9m）+ 视线方向点积（0.6）+ 距离惩罚评分，避免"明明看着却选中背后的东西"。
- **时间**：`rawDt`（上限 0.5s）驱动物理等待与按住计时，`dt`（上限 0.06s）驱动移动，保证低帧率机器上"12 秒显影"仍是 12 秒，不会变成慢动作。
- **暂停**：`PAUSE.on` 会清空按键、归零摇杆、取消按住、退出指针锁定、把 HUD 压到 18% 不透明度；`tick` 在暂停时只渲染不推进时间——所以药水、计时、灰尘全部冻结。`Esc` 与浏览器原生退锁事件之间有 340ms 防抖，两个入口不会互相打架。
- **适配**：`IS_MOBILE` 降低像素比与阴影、减少浮尘粒子；窄屏媒体查询单独调整 HUD 与面板排版。

**关于 AI**

本项目自主研发，开发中使用豆包模型（Doubao）作为工具完成。

- 全片只有一张真实照片：晾片绳上那张旧的，制作人自己拍的，转成黑白、补了纸边与颗粒，base64 内嵌。除此之外没有任何外部图片、模型文件或音频素材，也没有在线素材库调用。

## 五、设计取舍

- **不做战斗**：加了枪，这间屋子就变成"又一个射击场"。安静才是暗房的默认音量。
- **等待就是玩法**：显影 12 秒不是加载条，是让你站在红灯下听水声。想跳过的冲动，正是这个题材想让你忍的部分。
- **结局反转让"看照片"变成"被看见"**：第二张照片里是正在冲卷的你自己，走廊那头有人替你按了快门。
- **手机不做降级版**：同一份文件、同一套关卡，只换输入方式。
- **第二卷才把快门交给你**：第一卷必须由"别人"拍，反转才立得住；第二卷给玩家三格自由，冲出来一看——第三格里站着的还是你自己。自由是为了让这一下更凉。
- **暂停必须能真暂停**：计时冻结、按键清空、指针解锁，不是盖一层半透明遮罩假装停了。
- **一张真照片**：整间屋子都是程序画出来的，唯独绳上那张是实拍。它不参与谜题，也不给提示，只负责证明一件事——这间屋子里以前真的有人生活过。

## 七、已知取舍（诚实清单）

- 影棚背景纸近看仍有接缝，大画幅相机的剪影偏"投影仪"。
- 暗房整体偏亮偏橙，天花板接近全黑，光线过渡不算精细。
- 第一张照片是程序化剪影；第二张接触印相的前两格是真渲染，第三格仍是剪影——同一张纸上两种质感，凑近看能看出接缝。
- 绳上那张旧照片分辨率只有 512×684（再大就拖帧率），凑近看会糊；旧照片糊一点也算合理。
- 影棚整体很暗，自己拍的那两格靠自动测光提亮，颗粒比"正常曝光"重，全黑的一格会被判废。
- 手机首屏很暗（素材本来就是暗房），建议调高屏幕亮度再玩。

这些都属于"能接受的手工感"，没有藏起来的意思。
